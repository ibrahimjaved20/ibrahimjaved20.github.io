Grant data QA

I built a tool that cut a three-day grant review to one day.

  • Data quality
  • Automation
  • JSON schema conversion
  • NTEE codes NTEE stands for National Taxonomy of Exempt Entities. The codes classify nonprofit organizations by their main purpose and activities, such as education, health, or the arts.
Read the approach & limitations

Grant records need a consistent structure before they can support reliable research. I built this QA tool in one day. It maps JSON records to the required schema, checks field values and cross-field rules, and allows corrections in place. It reduced a three-day review process to one day.

What it checks

  • JSON records are mapped to the schema so fields, data types, allowed values, and word limits can be reviewed systematically.
  • Contradictions between fields, such as a funding minimum above the maximum or a deadline before the opening date.
  • NTEE classifications, with recognized codes converted into readable category names.
  • Date and stage structure, for records that run in cycles.

Paste one record or a large batch, get a verdict for each, fix problems in place, and download the result. It checks structure and rules. Whether a value matches the funder’s own page is still a source-verification step. It runs in the browser and uploads nothing.
